# Laporan & Notifikasi

## Laporan

Menu laporan tersedia untuk **Kepala Gudang**, **Staff Admin**, dan **Purchasing**. Jenis laporan yang tersedia:

- **Stok** — daftar barang dengan saldo, stok minimum, status kritis.
- **Mutasi Stok** — riwayat pergerakan stok dengan filter jenis dan tanggal.
- **Purchase Request** — daftar PR dengan status, urgensi, dan tanggal.
- **Purchase Order** — daftar PO dengan supplier, status, tanggal.
- **Pickup** — daftar permintaan pickup dengan status dan timeline.
- **Retur** — daftar retur dengan status, keputusan, penggantian.
- **Penerimaan & QC** — daftar penerimaan barang dengan hasil QC.

Cara mengakses laporan:

1. Klik menu **"Laporan"** di sidebar.
2. Pilih jenis laporan dari dropdown.
3. Atur filter yang tersedia (status, sumber, barang, rentang tanggal).
4. Data akan dimuat secara otomatis.
5. Klik **"Export"** untuk membuat file laporan dalam format **CSV** — prosesnya berjalan di background, status berubah dari "Pending" ke "Completed" sebelum file bisa diunduh.

## Notifikasi & kotak masuk

### Kotak masuk (inbox)

1. Klik ikon lonceng di sidebar atau header.
2. Daftar notifikasi akan ditampilkan, dengan yang terbaru di atas.
3. Filter: **All** atau **Unread**.
4. Klik notifikasi untuk menandai sudah dibaca.
5. Klik **"Mark all as read"** untuk menandai semua sudah dibaca.

### Push notification

Notifikasi muncul di perangkat Anda secara real-time saat ada:

- Permintaan approval (pickup, pembelian, retur)
- Status berubah (pickup siap diambil, PO terkirim)
- Penggantian barang siap
- Alert keamanan

:::tip
Klik notifikasinya (baik di Kotak Masuk maupun push notification) untuk langsung membuka halaman detail yang relevan — misalnya detail retur, purchase request, atau pickup terkait.
:::
