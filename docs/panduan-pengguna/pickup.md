# Pengambilan Barang (Pickup)

## Alur pengambilan

```text
Draft → Submitted → Checked → Prepared → Waiting Approval → Approved → Ready → Completed
```

:::info Catatan
Status bisa berubah menjadi **BACKORDERED** jika stok tidak tersedia, **REJECTED** jika ditolak, atau **CANCELLED** jika dibatalkan sebelum selesai.
:::

## Koperasi — membuat permintaan

1. Klik menu **"Request Saya"** di sidebar.
2. Klik tombol **"Buat Request"**.
3. Cari dan tambahkan barang yang ingin diambil.
4. Masukkan jumlah dan catatan (opsional) untuk setiap barang.
5. Klik **"Submit"** untuk mengirim permintaan.

## Staff Admin — menyiapkan & memenuhi

1. Klik menu **"Penyiapan & Pickup"**.
2. Jika stok tersedia: klik **"Mark Ready"**.
3. Jika stok tidak tersedia: status otomatis **BACKORDERED**.
4. Setelah disetujui, klik **"Fulfill"** untuk menandai selesai.

## Kepala Gudang — menyetujui

1. Klik menu **"Approval Pickup"**.
2. Lihat daftar permintaan yang menunggu persetujuan.
3. Klik **"Approve"** atau **"Reject"** (dengan alasan).
