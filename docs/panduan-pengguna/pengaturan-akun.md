# Pengaturan Akun

Akses pengaturan melalui menu **"Settings"** di dropdown user (klik avatar di pojok kanan atas).

## Profil

- Ubah nama dan email Anda.
- Perubahan email memerlukan verifikasi ulang.

## Keamanan

- Ubah password.
- Aktifkan 2FA dengan authenticator app.
- Daftar passkey untuk login tanpa password.

## Tampilan

- **Light** — mode terang.
- **Dark** — mode gelap.
- **System** — mengikuti pengaturan OS.

## Notifikasi

- Kelola preferensi notifikasi per jenis.
- Atur channel notifikasi yang diinginkan.
